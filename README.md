# Condensed-Matter-SpinIces
This is the code I wrote during my internship with the Theory of Condensed Matter group in the Cavendish Laboratory in 2023. I originally tracked this code on a different GitHub profile, but as that was associated with my university email, I lost access to it after graduation (I was not adequately prepared for the loss of that email).

Anyways, there are a lot of files on here and the gist of it is that each one represents an attempt, some successful and some unsuccessful, in making adding complexity to the system I had studied until that point. I will give more detailed explanations for each of them after I look through them again. The last file is not my code and is my supervisor's. I kept it as a reference.

The one of the non-programs, Hofstatder Butterfly (20x20 lattice), is an image I generated using the programs. (Definitely will explain the connections better later).
